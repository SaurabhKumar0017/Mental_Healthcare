# Mental Healthcare Support Platform

A web-based Mental Healthcare Support Platform designed to provide users with easy access to mental health resources, appointment booking, chat support, and contact information.

## Features

- Mental health support information
- Appointment booking interface
- Chat support interface
- Mental health resources
- Contact page
- Responsive and user-friendly web interface
- Simple navigation between different pages

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.

## Project Purpose

The purpose of this project is to create a simple web platform that brings together mental health information, resources, appointment-related functionality, chat support, and contact options in one place.
